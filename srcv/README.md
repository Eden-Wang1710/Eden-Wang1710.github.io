# SRCV interactive mid-report

Static research report and trajectory explorer. Entry points:

- `index.html`: report, experiments, figures, and the case-study trajectory entry.
- `trajectories/q68.html`: CLM-Agent / SRCV milestone comparison.

Open the HTML directly or serve this directory with any static HTTP server. No build step, external packages, analytics, or server is required. All links are relative, so the directory can be hosted at `/srcv/` on GitHub Pages.

The trajectory page uses curated milestones from the supplied Question 68 comparison, not reconstructed raw agent messages. It preserves grouped steps and labels approximate values. The trajectory includes the actual question and answer, recorded search terms, document IDs, and evidence excerpts, published with the owner’s explicit approval. Source abbreviations and grouped milestones remain; this is not a full raw-message replay. The website figures are SVGs converted directly from the author's latest remade PDFs, with text outlined for consistent rendering. Embedded icon metadata is removed while preserving pixel data. The full report is distributed separately by email.

Source snapshot: November 24, 2026.
